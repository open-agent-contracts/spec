# Initial v0 Changelog Entry - 2026-06-13

This entry records the initial v0 local staging baseline for the
public reference portal. Nothing in this entry implies that the
portal has been published, that a public repository exists, or that
a domain has been registered. Public publication is separately gated
and is not included in this baseline.

## What This Baseline Includes

- The Agent Operating Contract v0 schema documentation surface,
  including the closed enums for action effect class and gate, the
  receipt envelope, the versioning policy, and the two conformance
  levels (`minimal` and `complete`).
- Six synthetic contract examples covering hello-contract, read-only,
  reversible, external, irreversible, and anti-pattern shapes.
- Eight framework and export mapping pages: Model Context Protocol,
  Agent2Agent, OpenAPI, llms.txt, WebMCP, Anthropic Agent Skills,
  OpenAI Apps SDK, and vendor plugin metadata.
- A compatibility registry with eight initial rows and a static index
  page that applies a time-based freshness rule (green / yellow /
  red).
- A source-currency model with a page-header badge component, a
  maintainer-edited watchlist, a daily source-currency probe with
  issue-surface write semantics only, and a maintainer status
  dashboard.
- The first six guide pages: adding a contract by hand, validating
  your contract, exporting to Model Context Protocol, exporting to
  OpenAPI, exporting to Agent2Agent, and human review and
  authorization.
- This changelog entry.

## What This Baseline Does Not Include

- A public repository, served domain, or hosted portal.
- A public package, binary, marketplace listing, or commercial
  support surface.
- An endorsement or certification claim from any standards body,
  vendor, working group, or community project.
- Any execution gateway, account mutator, or runtime that calls
  third-party APIs.
- Any compliance certification or regulatory claim.

## Schema And Changelog Discipline

The portal CI is required to fail when the schema documentation
under `/standard/schema/` changes without a paired entry under
`/changelog/`. The rule is documented here so the discipline is
visible from the public surface; the workflow that enforces it
belongs to the portal-repo hygiene CI path and lives outside this
v0 baseline.

## Source-Currency Posture

Each mapping page carries a freshness badge that flips green,
yellow, or red based on the page's `verified_on` and
`next_review_due` frontmatter against the current build date. The
maintainer-edited watchlist pins primary sources and cadence values.
The probe emits issue payloads for content-hash changes without
writing to page frontmatter, the watchlist, or any portal data
file.
