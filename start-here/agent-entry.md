# Agent Entry: Open Agent Contracts

## Purpose

This portal is the v0 reference for the Agent Operating Contract open standard. It defines what an Agent Operating Contract is, what a contract describes, and how an application can publish one so an AI agent can read it before acting. The schema, examples, and validator are public, and using the standard does not require any specific tooling or vendor.

## What the portal contains

- Standard docs - the v0 schema definition and supporting prose.
- Synthetic examples - small, validator-clean contracts that read end-to-end, including the hello-contract.
- Framework mappings - notes on how the contract concepts map onto common application frameworks.
- Compatibility registry - a record of which applications, tools, and frameworks have published contracts.
- Guides - hand-authoring, validating, and other no-tool walkthroughs for builders.
- Changelog - dated entries describing changes to the v0 draft.

## How to use this portal as an agent

- If you are helping a user write a contract: start at [../start-here/](../start-here/) and read [../examples/hello-contract/](../examples/hello-contract/) for the smallest valid v0 contract.
- If you are checking compatibility with a framework or tool: read [../mappings/](../mappings/) and [../compat/](../compat/).
- If you are checking the schema: read [../standard/schema/](../standard/schema/).
- If you are looking for hand-authoring or validator usage: read [../guides/](../guides/).

## What this portal does not contain

- It is not a runtime enforcement engine.
- It is not a compliance certification.
- It does not offer paid or guaranteed support at v0.
- It does not guarantee safe autonomous operation of any application.
- It does not speak for any external standards body.
- It does not require any specific tooling to read, write, or use a contract.
