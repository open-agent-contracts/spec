Source-currency badge fixture

This fixture renders the three badge states against a fixed build date of 2026-06-14. The rule (CONCEPT-002 plan section 5.1) is:

  • green when today < next_review_due - 30 days,
  • yellow when today is inside the 30-day window before next_review_due,
  • red when today >= next_review_due.

Yellow: next_review_due = 2026-07-13

verified_onnext_review_duedays until duebadge
2026-06-13 2026-07-13 29 Review soon

Red: next_review_due = 2026-06-01

verified_onnext_review_duedays until duebadge
2026-03-01 2026-06-01 -13 Past due

The badge component itself is inert. The portal build renders the status word, the colour modifier class, and the data-* attributes from page frontmatter; the rendered page never calls a network endpoint or runs JavaScript to flip the badge.
